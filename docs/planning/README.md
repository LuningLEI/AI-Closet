# Active plans

The project currently has three active plans with different scopes.

| Horizon | Plan | Purpose |
|---|---|---|
| Near term | [Recommendation and Taste quality](near-term-recommendation-quality.zh-CN.md) | Improve retrieval, feedback attribution, exploration, immediate reranking, logging, and evaluation validity |
| Sandy 11 | [Recognition, Agent, onboarding, and incremental add-ons](sandy-11-todo.zh-CN.md) | Fix category confusion, complete trip planning, improve preference cold-start, and avoid full rebuilds for new shoes/accessories |
| Productization | [Production architecture and reliable cloud VLM](production-architecture-vlm-roadmap.md) | Make recognition schema-safe, provider-independent, secure, observable, deployable, and App Store ready |
| Long term | [Portfolio readiness](portfolio-readiness.md) | Produce current-version evidence, performance/cost measurements, a safe demo, and a public portfolio release |

The near-term plan changes recommendation quality. The productization plan owns
recognition reliability, cloud inference, production security, deployment, and
App Store readiness. The long-term plan packages and validates the project for
professors, recruiters, and repository reviewers. A task may support more than
one plan, but its acceptance criteria should be recorded in only one primary
plan to avoid duplicated status.

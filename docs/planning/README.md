# Active plans

The project currently has two active plans with different scopes.

| Horizon | Plan | Purpose |
|---|---|---|
| Near term | [Recommendation and Taste quality](near-term-recommendation-quality.zh-CN.md) | Improve retrieval, feedback attribution, exploration, immediate reranking, logging, and evaluation validity |
| Long term | [Portfolio readiness](portfolio-readiness.md) | Produce current-version evidence, performance/cost measurements, a safe demo, and a public portfolio release |

The near-term plan changes recommendation quality. The long-term plan packages
and validates the project for professors, recruiters, and repository reviewers.
A task may support both plans, but its acceptance criteria should be recorded in
only one primary plan to avoid duplicated status.

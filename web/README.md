# Web

Next.js + TypeScript frontend for AI Closet.

## Responsibilities

- Supabase Auth user flow
- Closet upload and inventory views
- Profile and preference management
- Today's weather-aware outfit page
- Recommendation workspace
- Agent chat surface

## Run

```bash
cd web
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
cd web
npm run build
```
